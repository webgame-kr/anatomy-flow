# assets/licenses/

배포하는 모든 자산(모델, 텍스처, 애니메이션)의 라이선스와 출처 표기를 이 폴더에 둡니다.

- 자산 목록과 상태는 `docs/references/asset_registry.csv`가 원본입니다.
- 공개 배포할 자산은 라이선스 원문이나 링크, 그리고 출처 표기 문구를 `<asset_id>.md`로 남깁니다.
- `verification_status`가 확인되지 않은 자산은 `assets/`에 커밋하지 않습니다.
- NC(비상업), SA(동일조건) 조건이 있는 자산은 사용 전에 프로젝트 전체 라이선스에 미치는 영향을 검토합니다.
