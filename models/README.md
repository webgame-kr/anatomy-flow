# models/

> **2026-11-27 안내:** 배포용 모델은 이제 `assets/anatomy/<계통>/`(해부학)과 `assets/test-models/`(테스트)에 둡니다. 원본은 `raw-models/`에 둡니다. 이 폴더는 STEP 01 문서와 맞추기 위해 남겨 두었고, STEP 02에서 `assets/`로 통합할 예정입니다.

3D 모델 파일(GLB) 자리입니다. STEP 01은 정육면체·구체·원통 같은 기본 도형만 쓰므로 비어 있습니다.

원칙 (STEP 02 이후)
- 브라우저에서 바로 읽을 수 있는 `.glb`(glTF 2.0 바이너리)만 둡니다.
- 파일 이름은 소문자와 하이픈만 씁니다. 예: `heart-basic.glb`
- 모델 안 각 부위(Mesh) 이름은 콘텐츠 JSON의 모델 ID와 맞춥니다.
- 라이선스가 자유로운 모델만 커밋합니다(출처와 라이선스를 `models/SOURCES.md`에 기록).
